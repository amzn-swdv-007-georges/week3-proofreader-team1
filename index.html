What is GitHub Pages?

GitHub Pages is a free hosting service provided by GitHub. It allows you to publish a static website directly from a repository.

How does it work?

  1. Create an index.html file.
  2. Push it to GitHub.
  3. Enable GitHub Pages in the repository settings.
  4. GitHub publishes the site automatically.

Why is it useful?

  • Free website hosting
  • Portfolio sites
  • Project documentation
  • Status dashboards
  • Course and workshop pages
